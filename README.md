# nixos-plymouth

Plymouth boot splash themes built from the official [NixOS branding](https://github.com/NixOS/branding)
assets. The logomark SVG is generated by the branding flake at build time and rendered to PNG frames.

## Themes

### `nixos-default`

![nixos-default animation](themes/default/preview.gif)

NixOS logomark centered on black. It winds up counter-clockwise, then spins forward a full turn, and
repeats. When a password is requested (LUKS unlock) a blinking cursor appears centered
below the logo, with a dot per typed character. No prompt text or input box.

Animation timings live at the top of `themes/default/render-frames.py`. After changing them, regenerate
the preview above with `nix run .#update-preview`.

## Usage

```nix
# flake.nix of your system
inputs.nixos-plymouth.url = "github:iltgg/nixos_plymouth";

# configuration
imports = [ inputs.nixos-plymouth.nixosModules.default ];
services.nixos-plymouth.enable = true;
```

## Development

```sh
nix develop               # rsvg-convert, imagemagick, python3 for running scripts by hand
nix build .#default       # theme -> result/share/plymouth/themes/nixos-default
nix build .#preview       # animated GIF of one loop
nix run .#update-preview  # write each theme's GIF to themes/<name>/preview.gif
nix fmt
```

## Testing the splash live

The theme has to be installed on the running system (enable the module and rebuild). Then, from a
text VT (e.g. Ctrl+Alt+F3), outside `nix develop` so the system plymouth is used:

```sh
# ./test.sh
sudo plymouthd
sudo plymouth --show-splash
sleep 5
sudo plymouth ask-for-password --prompt "Please enter passphrase"
sudo plymouth quit
```
