# nixos-plymouth

Plymouth boot splash themes built from the official [NixOS branding](https://github.com/NixOS/branding)
assets. The logomark SVG is generated by the branding flake at build time and rendered to PNG frames.

## Themes

All themes center the NixOS logomark on black. When a password is requested (LUKS unlock) a
blinking cursor appears centered below the logo, with a dot per typed character. No prompt text or
input box.

### `spin`

![nixos-spin animation](themes/spin/preview.gif)

The logo winds up counter-clockwise, then spins forward a full turn.

### `glow`

![nixos-glow animation](themes/glow/preview.gif)

The lambdas light up clockwise around the logo.

### `/boot` usage

Plymouth and the theme are packed into the initrd, so they take space in `/boot` for every
generation with its own initrd. Measured by building a minimal x86_64 NixOS initrd (default zstd
compression, Linux 6.18):

| Initrd                            | Size    | Added vs. no Plymouth | Added vs. stock Plymouth (`bgrt`) |
| --------------------------------- | ------- | --------------------- | --------------------------------- |
| No Plymouth                       | 29.7 MB | —                     | —                                 |
| Stock Plymouth (`bgrt` theme)     | 37.2 MB | +7.5 MB               | —                                 |
| `spin`                            | 38.0 MB | **+8.3 MB**           | **+0.8 MB**                       |
| `glow`                            | 40.0 MB | **+10.3 MB**          | **+2.8 MB**                       |

Most of the cost is Plymouth itself (binaries, renderers, fonts). If you already use Plymouth, the
theme adds only the last column. Exact numbers depend on your kernel and initrd configuration.

### Layout

Each theme is a directory under `themes/` with a `package.nix` and a `render-frames.py` that
describes its animation; timings and colors are constants at the top of that file. Everything
else (the Plymouth script, password cursor, frame rendering and packaging) is shared in
`themes/common/`. To add a theme, create its directory and add its name to `themes` in
`flake.nix`. After changing an animation, regenerate the previews with `nix run .#update-preview`.

## Usage

```nix
# flake.nix of your system
inputs.nixos-plymouth.url = "github:iltgg/nixos_plymouth";

# configuration
imports = [ inputs.nixos-plymouth.nixosModules.default ];
services.nixos-plymouth.enable = true;
services.nixos-plymouth.theme = "glow"; # or "spin" (the default)
```

## Development

```sh
nix develop                                # rsvg-convert, pngquant, imagemagick, python3 for running scripts by hand
nix build .#nixos-plymouth-<name>          # theme -> result/share/plymouth/themes/nixos-<name>
nix build .#nixos-plymouth-<name>-preview  # animated GIF of one loop
nix run .#update-preview                   # write each theme's GIF to themes/<name>/preview.gif
nix fmt
```

## Testing the splash live

The theme has to be installed on the running system (enable the module and rebuild). Then, from a
text VT (e.g. Ctrl+Alt+F3), outside `nix develop` so the system plymouth is used:

```sh
# ./test.sh
sudo plymouthd
sudo plymouth --show-splash
sleep 5
sudo plymouth ask-for-password --prompt "Please enter passphrase"
sudo plymouth quit
```
